# Code Control

## Description
> *Harriet stöter på en låst dörr. Bredvid den sitter en terminal som blinkar rött och visar en text som varnar för att programmet som styr dörren både förbrukar för mycket minne och är för långsamt.*
> *För att ta sig igenom behöver Harriet fixa koden, men eftersom hon låtit en språkmodell skriva det mesta av hennes kod de senaste åren känner hon sig lite ringrostig.*
> *Efter att ha bankat och slagits med VIM ett tag ser hon en poster på väggen intill, den gör reklam för CASCADAS nya kodgranskningstjänst. Med hjälp av denna kan hon kanske få några tips på hur hon fixar minnesläckorna och for-looparna i styrsystemet?*
> *Kan du hjälpa Harriet att ta sig igenom dörren, eller kanske komma åt något ännu mer intressant...?*
> *Du kan surfa till kodgranskningstjänsten på [https://undutmaning-code-control.chals.io](https://undutmaning-code-control.chals.io).*
